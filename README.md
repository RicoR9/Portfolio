# Portfoolio ja projektid

See repositoorium koondab minu arenduse portfoolio ja erinevad iseseisvad projektid. Siin on nii backend kui ka frontend lahendusi, mille eesmärk on näidata minu oskusi ja arengut veebiarendajana.

## Projektid

### Movie Collection API
REST API filmikogumi haldamiseks.  
Projekt sisaldab juhendit, kuidas:
- rakendust käivitada  
- API endpointe testida  

Eesmärk oli harjutada backend-arendust.

---

### Lihtne HTML & CSS veebileht
Vabast ajast tehtud staatiline veebileht, mis on loodud ainult HTML-i ja CSS-i kasutades.  
Eesmärk oli harjutada:
- kujundust (layout, responsive design)  
- puhta frontendi kirjutamist ilma frameworkideta  

---

### Portfoolio (CSR & SSR)
Kaks Reactil põhinevat portfoolio versiooni:
- **CSR (Client-Side Rendering)**  
- **SSR (Server-Side Rendering)**  

Projektid on hetkel pooleli, kuid nende eesmärk on:
- mõista erinevust CSR ja SSR vahel  
- katsetada erinevaid renderdamise lähenemisi  

CSR versioon on deploy'tud ja kättesaadav siin:  
http://ricoportfolio.eu  

---

### Veebipood (/shop endpoint)
CSR portfoolio sees olev `/shop` endpoint sisaldab lihtsat veebipoodi, mis on loodud kasutades:
- WordPress  
- WooCommerce  

Eesmärk oli tutvuda e-kaubanduse lahendustega ja nende integreerimisega.
